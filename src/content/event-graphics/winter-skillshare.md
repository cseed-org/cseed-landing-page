Four sessions, run twice so you can attend two of them. Everything is beginner-friendly
and no session assumes you attended a previous one.

## Sessions

- **Facilitating hard conversations** — practical, role-play heavy.
- **Budgeting a student event** — the actual forms, with the actual deadlines.
- **Zine making** — materials provided.
- **Intro to grant writing** — bring a project idea if you have one.
